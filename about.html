About Movie Finder

Movie Finder is a simple movie discovery application created as a mini project using HTML, CSS, JavaScript, and a movie API.

It allows users to:

  • Search movies, series, and episodes with type and year filters
  • View detailed information including plot, cast, awards, box office, and ratings from IMDb, Rotten Tomatoes, and Metacritic
  • Browse every season and episode of a TV series
  • Discover featured and popular titles
  • Create and manage a personal watchlist and track what you've watched

Technologies Used

  • HTML5: Semantic web structure
  • CSS3: Modern dark mode styling & responsive grid layouts
  • JavaScript (Vanilla): DOM manipulation, API fetching, and state management
  • OMDb API: Dynamic third-party movie metadata source
  • Python FastAPI + SQLite: User accounts with bcrypt-hashed passwords
  • LocalStorage / SessionStorage: Watchlist, recent searches, and offline fallback accounts

Features

  • Real-time search with filters, pagination, and recent searches
  • Detailed view modal with multi-source ratings and IMDb links
  • Season and episode browser for TV series
  • Per-user watchlist with watched tracking, sorting, and filters
  • Authentication via FastAPI backend, with LocalStorage fallback
  • Fully responsive layout for mobile, tablet, and desktop
