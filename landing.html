Frequently Asked Questions

Movie Finder is a web application built using HTML5, CSS3, Vanilla JavaScript, a FastAPI backend, and the OMDb API for discovering movies and creating custom watchlists.
When running with the Python FastAPI backend, accounts are stored in a SQLite database with bcrypt-hashed passwords. If the pages are opened without the backend, the app falls back to browser LocalStorage so the demo still works.
Movie information, plots, ratings (IMDb, Rotten Tomatoes, Metacritic), episodes, and posters are fetched in real-time from the OMDb API.
